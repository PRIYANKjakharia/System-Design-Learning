# One Last Topic (Often Missed)

These aren't separate technologies—they're the trade-offs you'll constantly evaluate as a backend engineer.

- Trade-off Analysis
- Cost vs Performance
- Consistency vs Availability
- Latency vs Throughput
- Read-heavy vs Write-heavy Systems
- SQL vs NoSQL
- Monolith vs Microservices
- Synchronous vs Asynchronous Communication
- Push vs Pull
- Strong Consistency vs Eventual Consistency
